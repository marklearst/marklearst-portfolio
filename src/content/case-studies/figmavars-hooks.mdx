<CaseStudySection title="Bring Figma Variables into React">
  <div className="space-y-6">
    <CaseStudyParagraph>
      Design systems teams were copying tokens from Figma into code by hand,
      and the variable versions drifted between the two. I built FigmaVars
      Hooks so React apps could read Figma Variables from the official API.
    </CaseStudyParagraph>

    <CaseStudyDetails summary="Token synchronization problems">
    <CaseStudyMutedList className="space-y-3">
      <li>Manual copy-paste workflows to sync design tokens from Figma to code</li>
      <li>Version drift between Figma variables and application code</li>
      <li>No way to validate variables at runtime in React apps</li>
      <li>No way to load Figma variables live in Storybook or dev tools</li>
      <li>Token export tools that didn't use the official APIs</li>
    </CaseStudyMutedList>
    </CaseStudyDetails>
  </div>
</CaseStudySection>

<CaseStudySection title="Keep credentials out of the browser">
  <div className="space-y-6">
    <CaseStudyParagraph>
      <strong>FigmaVars Hooks</strong> is a React 19 hooks library with typed
      access to the Figma Variables REST API, plus a CLI that exports variables
      in CI/CD pipelines.
    </CaseStudyParagraph>

    <CaseStudyMutedText>
      In the browser, the hooks read approved token data exported as JSON in
      the Figma Variables API response format. Authentication stays on the
      server or in the build and export step, so credentials never reach the
      browser.
    </CaseStudyMutedText>

    <CaseStudyMutedText>
      Teams without Enterprise can export the JSON once and pass it to{' '}
      <code>fallbackFile</code> for static or local environments. Storybook and
      design system dashboards stay in sync that way, with no live API calls.
    </CaseStudyMutedText>

    <CaseStudyMutedText>
      Type guards and error helpers let apps validate the data and handle API
      failures by status code.
    </CaseStudyMutedText>

    <CaseStudySubheading>Offline fallback</CaseStudySubheading>

    <CodeBlock
      language="tsx"
      analyticsLabel="figma_vars_hooks_fallback"
      code={[
        "import exportedVariables from './figma-variables.json'",
        "",
        "<FigmaVarsProvider",
        "  token={null}",
        "  fileKey={null}",
        "  fallbackFile={exportedVariables}",
        ">",
        "  <App />",
        "</FigmaVarsProvider>",
      ].join('\n')}
    />


    <CaseStudyDetails summary="Hooks, CLI, Storybook, and validation examples">
    <CaseStudySubheading className="mt-0">Hooks and provider</CaseStudySubheading>

    <CodeBlock
      language="tsx"
      analyticsLabel="figma_vars_hooks_quick_start"
      code={[
        "import { FigmaVarsProvider, useVariables } from '@figma-vars/hooks'",
        "",
        "import exportedVariables from './figma-variables.json'",
        "",
        "export function App() {",
        "  return (",
        "    <FigmaVarsProvider",
        "      token={null}",
        "      fileKey={null}",
        "      fallbackFile={exportedVariables}",
        "    >",
        "      <Variables />",
        "    </FigmaVarsProvider>",
        "  )",
        "}",
        "",
        "function Variables() {",
        "  const { data, isLoading, error } = useVariables()",
        "  if (isLoading) return <div>Loading...</div>",
        "  if (error) return <div>Error: {error.message}</div>",
        "  const variables = Object.values(data?.meta.variables ?? {})",
        "  return <pre>{JSON.stringify(variables, null, 2)}</pre>",
        "}",
      ].join('\n')}
    />

    <CaseStudySubheading>Hooks API</CaseStudySubheading>
    <CaseStudyMutedText>
      The hooks fetch and cache Figma variables at runtime:
    </CaseStudyMutedText>
    <CaseStudyMutedList className="space-y-2">
      <li><code>useVariables()</code> fetches all variables from a Figma file</li>
      <li><code>useVariableById()</code> gets one variable by ID</li>
      <li><code>useVariableCollections()</code> reads variable collections</li>
      <li>Built-in caching and request deduplication</li>
      <li>Exported response types and type guards</li>
      <li>SWR configuration for revalidation, retry, and cache control</li>
    </CaseStudyMutedList>

    <CaseStudySubheading>CLI export</CaseStudySubheading>
    <CaseStudyMutedText>
      The <code>figma-vars-export</code> CLI exports Figma variables as JSON in
      CI/CD pipelines:
    </CaseStudyMutedText>
    <CaseStudyMutedList className="space-y-2">
      <li>Runs in GitHub Actions or any CI environment</li>
      <li>Writes JSON that Style Dictionary can read</li>
      <li>Filters by collection, mode, or variable name</li>
      <li>Validates exported data with runtime guards before writing</li>
    </CaseStudyMutedList>
    <CodeBlock
      language="bash"
      analyticsLabel="figma_vars_hooks_cli_export"
      code={[
        "FIGMA_TOKEN=your_token npx figma-vars-export --file-key YOUR_FILE_KEY --out ./figma-variables.json",
        "",
        "FIGMA_TOKEN=your_token figma-vars-export --file-key YOUR_FILE_KEY --out ./figma-variables.json",
        "",
        "figma-vars-export --help",
      ].join('\n')}
    />

    <CaseStudySubheading>Storybook integration</CaseStudySubheading>
    <CaseStudyMutedText>
      Wrap stories once and every component doc reads from the approved JSON
      export. Re-export when the approved variables change:
    </CaseStudyMutedText>
    <CodeBlock
      language="tsx"
      analyticsLabel="figma_vars_hooks_storybook"
      code={[
        "// .storybook/preview.tsx",
        "import { FigmaVarsProvider } from '@figma-vars/hooks'",
        "import type { Preview } from '@storybook/react'",
        "",
        "import exportedVariables from './figma-variables.json'",
        "",
        "const preview: Preview = {",
        "  decorators: [",
        "    Story => (",
        "      <FigmaVarsProvider",
        "        token={null}",
        "        fileKey={null}",
        "        fallbackFile={exportedVariables}",
        "      >",
        "        <Story />",
        "      </FigmaVarsProvider>",
        "    ),",
        "  ],",
        "}",
        "",
        "export default preview",
      ].join('\n')}
    />

    <CaseStudySubheading>Runtime guards and errors</CaseStudySubheading>

    <CaseStudyMutedList className="space-y-2">

      <li><code>isPublishedVariablesResponse()</code> validates published data</li>
      <li><code>isFigmaApiError()</code> and helpers for handling status codes</li>
      <li><code>redactToken()</code> for safe logging and support flows</li>
    </CaseStudyMutedList>

    <CaseStudyMutedList className="space-y-2">
      <li>Every hook, including edge cases</li>
      <li>Mocked API requests and responses, and error handling</li>
      <li>Runtime validation for all data structures</li>
      <li>CLI command execution and file output</li>
    </CaseStudyMutedList>
    </CaseStudyDetails>
  </div>
