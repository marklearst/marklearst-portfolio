<CaseStudySection title='Modernize the foundation of an existing library'>
  <div className='space-y-6'>
    <CaseStudyParagraph>
      Hailstorm is the Abusix design system. I maintain a fork focused on its
      component foundation. The original system shipped real
      UI, but the stack had fallen behind modern React patterns, token
      workflows, and accessibility expectations. I wanted to upgrade those
      foundations while preserving the APIs product teams used.
    </CaseStudyParagraph>
    <CaseStudyMutedList className='space-y-3'>
      <li>Legacy tooling made it hard to evolve components safely</li>
      <li>Tokens existed but lacked a clear, enforceable workflow</li>
      <li>Storybook docs did not reflect the actual production APIs</li>
      <li>Accessibility defaults needed to align with WCAG 2.2 AA</li>
      <li>QA coverage was fragmented and hard to trust</li>
    </CaseStudyMutedList>
    <CaseStudyParagraph>
      The modernization had to keep API stability while moving to
      React 19, Tailwind v4 tokens, Storybook 10, and
      consistent automated tests.
    </CaseStudyParagraph>
  </div>
</CaseStudySection>
