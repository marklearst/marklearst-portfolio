# DM Sans webfonts

DM Sans is the primary sans-serif family. These unmodified WOFF2 files were retrieved from the official Google Fonts delivery service on September 15, 2026. They include variable weights 100–1000, optical sizes 9–40, and true roman and italic styles. The existing MonoLisa remains the code family.

- Project: https://github.com/googlefonts/dm-fonts
- Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/dmsans
- License: [SIL Open Font License 1.1](OFL.txt)
- CSS manifest: https://fonts.googleapis.com/css2?family=DM+Sans:ital,opsz,wght@0,9..40,100..1000;1,9..40,100..1000&display=swap
